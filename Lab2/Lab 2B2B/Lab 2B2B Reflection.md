# Lab 2B2B Reflection 

- In this lab, I used Apache access logs to check what requests were made to the web server.

- I first tested the home page, PDF link, and a missing page so that the log file would have different results like `200` and `404`.

- I used commands like `grep`, `sort`, `uniq`, and `head` to filter the log and count useful information.

- I also tried scripts for failed requests, CSV output, and user-agent details.

- I found this lab useful because the log file shows what is happening behind the web server, not just what we see in the browser.

- This can be useful in cybersecurity because logs can help to find failed requests, unusual IP addresses, and repeated access attempts.
