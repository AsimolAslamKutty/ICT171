# Lab 2B2A Reflection 

- In this lab, I practised using Linux commands to create folders, create files, copy, rename, and delete files.

- I used commands like `mkdir`, `cat`, `cp`, `mv`, and `rm`. These commands helped me get more comfortable with managing files from the terminal.

- I also created simple Bash scripts and learnt how `#!/bin/bash` tells the system to run the file as a Bash script.

- I used `chmod 777` to give permission for the script to run, then tested the script from the terminal.

- The loop and conditional script helped me understand how a script can repeat steps and check the user’s input.

- I also used commands like `free -h`, `df -h`, and `top` to check memory, disk usage, and running processes.

- This lab helped me see how Bash scripting can save time because repeated commands can be placed inside one script instead of typing them one by one.
