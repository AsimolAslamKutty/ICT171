# Lab 2B2C Reflection 

- This lab showed me how a Linux server can be checked after it is already running.

- I used tools like `netstat` and `nmap` to see which ports were open. This helped me understand that a web server is not only about showing a webpage, but also about checking what services are listening in the background.

- The `tcpdump` activity was useful because I could actually see network packets being captured while the ping command was running.

- I also worked with system logs and Apache access logs. This made me realise that logs are important when we need to check errors, requests, or unusual activity on a server.

- Webalizer was interesting because it changed the log information into a report that was easier to read compared to looking at raw log lines.

- From this lab, I understand better why monitoring is important for server administration. Without monitoring, it would be hard to know whether the server is working properly or whether something suspicious is happening.

- I think the most useful part was learning how to check ports and logs, because these are things that can help when troubleshooting a real web server.
