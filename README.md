# ICT171 Reflection Journal

This repository contains my ICT171 lab works, screenshots and reflection notes. 
In these labs, I practiced different Linux and cloud tasks. Some of the things I worked on include setting up Ubuntu, using terminal commands, managing files and permissions, creating users and groups, writing Bash scripts, using AWS EC2, setting up Apache, using DNS and HTTPS, monitoring server activity, creating backups and installing an additional server service, which I chose as MariaDB.
I used this journal to organise my work and keep track of what I completed for each labs. The screenshots show the steps I did and the reflection notes explain what I understood from the labs.
