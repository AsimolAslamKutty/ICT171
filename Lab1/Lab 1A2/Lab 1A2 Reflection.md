# Lab 1A2 Reflection

- I found the Ubuntu GUI easier to start with because it felt more familiar. Using Firefox, LibreOffice, File Manager, and the Software Centre was quite straightforward because I could click around and see what I was doing.

- The command line was harder at first because I had to type the correct commands and remember the options. Some commands also looked quite similar, so I had to slow down and check what each one was actually showing.

- After practising commands like `ls`, `ps`, `top`, `ip a`, `ping`, `nslookup`, and `whois`, I understood that the CLI gives more detailed system information compared to the GUI. It is not as visual, but it is more useful for checking processes, files, network settings, and system details.

- For software installation, I found the Software Centre easiest for normal desktop use. However, `apt` feels more useful for Linux and server tasks because it is faster and more direct. Downloading `.deb` files and compiling from source also showed me that Linux has different ways to install software, but those methods need more care.

- As a normal user, I would still prefer the GUI. For future IT or developer work, I think I need to get more comfortable with the CLI because it is better for troubleshooting and managing systems.
