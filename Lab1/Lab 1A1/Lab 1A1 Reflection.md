## Setup Summary

- I used Oracle VirtualBox to run Ubuntu on my Windows laptop. This was useful because I could practise Linux in a separate environment without changing anything on my main Windows system. My screenshot `1a1_01 virtualbox installed` shows the Ubuntu virtual machine inside VirtualBox.

- I downloaded the Ubuntu ISO file because it is needed to install Ubuntu into the virtual machine. The ISO file works like the installer for the Ubuntu operating system. This is shown in `1a1_02_ubuntu_iso_downloaded`.

## What I Learnt

- I learnt that a virtual machine lets me run another operating system inside my laptop without replacing Windows.

- I understood that Ubuntu inside VirtualBox still depends on my laptop’s resources, such as RAM, storage, and network connection.

- I learnt that the VM settings matter because wrong settings can affect how Ubuntu runs or connects to the internet.

- I also learnt that NAT and Bridged networking are not the same. NAT is simpler for internet access, while Bridged makes the VM act more like another device on the same network.

- This setup helped me understand why virtual machines are useful for IT labs because I can test Linux commands safely without affecting my main computer.

## Challenges

- At first, I was not very familiar with VirtualBox, so I had to take some time to find the correct settings.

- The network setting was a bit confusing at the beginning because I was not fully sure what NAT and Bridged meant.

- After checking the settings and running Ubuntu successfully, I became more comfortable using the VM for the next labs.
